# AutoJoin Welcome Bot

Telegram bot for channel join-request auto-approval, per-channel welcome messages, deep-link tracking, broadcasts, user export, and SQLite backup/restore.

## Important Telegram limitations

- Add the bot as a **Channel Administrator** and grant **Invite Users / Add Subscribers** permission.
- Telegram only allows the bot to contact a join requester through `ChatJoinRequest.user_chat_id` for a short period (up to 5 minutes). The bot sends the welcome DM immediately after approval.
- The welcome button opens `https://t.me/<bot>?start=w_<channel_id>`. Telegram opens the bot chat with a **Start** action; the user must tap Start. A bot cannot force-send `/start`.
- "Button Clicked Users" is tracked when the user starts the bot through this deep link. Telegram does not send a separate callback for clicking a URL button.
- Users who have not started the bot cannot receive later broadcasts. They are listed separately as not started, but broadcast is only available to users who started the bot.
- Use this bot only for users who expect your updates. Respect Telegram limits and applicable privacy/anti-spam rules.

## 1. Create your bot

1. Open [@BotFather](https://t.me/BotFather).
2. Send `/newbot` and follow the steps.
3. Copy the token.
4. Find your numeric Telegram user ID using a trusted ID bot or Telegram client.

## 2. Configure Render

1. Upload this ZIP's extracted files to a GitHub repository.
2. In Render, choose **New + → Blueprint** and select the repository, or create a **Web Service** manually.
3. Build command: `pip install -r requirements.txt`
4. Start command: `python bot.py`
5. Set environment variables:
   - `BOT_TOKEN` = BotFather token
   - `ADMIN_IDS` = your numeric Telegram user ID (multiple IDs comma-separated)
   - `DB_PATH` = `/var/data/bot.db`
   - `BACKUP_DIR` = `/var/data/backups`
   - `USE_WEBHOOK` = `true`
   - `PUBLIC_URL` = your Render service URL (for example `https://your-service.onrender.com`). The code can also read Render's `RENDER_EXTERNAL_URL` automatically.
6. Attach a persistent disk mounted at `/var/data` if your Render plan supports it. Without persistent storage, SQLite data and local backups can be lost when the service is redeployed/restarted. Download backups regularly.
7. Deploy and open your bot; send `/start`, then `/panel`.

**Hosting note:** A continuously available Web Service and persistent disk may require a paid Render plan. Check Render's current plan limits before deploying. Do not assume a free instance will run 24/7 or preserve local files.

## 3. Add a channel

1. Add the bot as an administrator in your channel.
2. Enable **Invite Users / Add Subscribers** permission.
3. Get the channel ID (usually starts with `-100`). For a private channel, the bot must be an admin to access it.
4. In the bot's private chat, send:
   `/addchannel -1001234567890`

The bot verifies its admin status and stores the channel.

## 4. Set welcome text and button

Send:
- `/welcome -1001234567890` then send the welcome text.
- `/button -1001234567890` then send the button label.

Placeholders supported in welcome text:
- `{first_name}`
- `{username}`

Example:
`🎉 Welcome {first_name}! Thanks for joining ❤️`

The button URL and start payload are generated automatically per channel.

## 5. Admin features

Use `/panel` for the inline admin panel:
- My Channels
- Welcome Setup instructions
- Button Setup instructions
- Broadcast audience selection
- User database counts
- Statistics
- Backup and restore

Commands:
- `/panel`
- `/addchannel -100...`
- `/welcome -100...`
- `/button -100...`
- `/exportusers`
- `/cancel`

Broadcast supports Telegram messages copied from your admin chat, including text, photo, video, and documents. Select all started users or users who started through a welcome button. The "not started" join-request audience is shown for reference only and cannot be messaged until they start the bot.

## 6. Backup & Restore

- Use `/panel → Backup & Restore → Create & Download Backup`.
- Keep a copy outside Render.
- Restore accepts a `.db` backup generated by this bot and creates a safety backup before replacement.

## 7. Security

- Never upload `.env` or your Bot Token to GitHub.
- Set `ADMIN_IDS` correctly. Only those numeric IDs can use admin actions.
- If your token is exposed, revoke it with BotFather immediately and set the new token in Render.
